# API контракта

## Данные

**Кабинет (Room):**
- `id` (number) — идентификатор
- `name` (string) — название

**Бронь (Booking):**
- `id` (number) — идентификатор
- `roomId` (number) — идентификатор кабинета
- `date` (string) — дата в формате `ГГГГ-ММ-ДД`
- `start` (string) — время начала в формате `ЧЧ:ММ`
- `end` (string) — время окончания в формате `ЧЧ:ММ`
- `name` (string) — кто бронирует

## Эндпоинты

### GET /api/rooms

Список кабинетов.

**Ответ:** 200, массив кабинетов

```json
[
  { "id": 1, "name": "Кабинет 101" },
  { "id": 2, "name": "Кабинет 102" },
  { "id": 3, "name": "Лекционный зал" }
]
```

---

### GET /api/bookings

Список броней.

**Параметры запроса:**
- `date` (необязательно) — фильтр по дате

**Ответ:** 200, массив броней, отсортированных по дате и времени

```json
[
  { "id": 1, "roomId": 1, "date": "2026-11-03", "start": "10:00", "end": "11:30", "name": "Анна" }
]
```

---

### POST /api/bookings

Создать бронь.

**Тело запроса:**

```json
{ "roomId": 1, "date": "2026-11-03", "start": "10:00", "end": "11:30", "name": "Анна" }
```

**Ответы:**
- 201 — бронь создана, возвращает бронь с `id`
- 400 — некорректный JSON
- 404 — кабинет не найден
- 409 — кабинет в это время уже занят
- 422 — неверные данные (пустое имя, неверный формат, конец не позже начала)

```json
{ "error": "текст ошибки" }
```

---

### DELETE /api/bookings/{id}

Отменить бронь.

**Ответы:**
- 204 — бронь отменена (без тела)
- 404 — бронь не найдена

## Коды ошибок

| Код | Значение |
|-----|----------|
| 400 | Тело запроса не является корректным JSON |
| 404 | Кабинет или бронь не найдены |
| 409 | Кабинет в это время уже занят |
| 422 | Неверные данные: пустое имя, неверный формат даты или времени, конец не позже начала |
